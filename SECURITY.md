# Política de segurança

## Versões suportadas

O projeto está em fase de MVP. Correções de segurança são aplicadas somente à versão mais recente da branch `main`.

## Relato responsável

Não publique credenciais, dados privados ou detalhes exploráveis em issues públicas. Entre em contato de forma privada com o mantenedor pelo perfil do GitHub e inclua:

- descrição da vulnerabilidade;
- componente e versão afetados;
- passos mínimos para reprodução;
- impacto estimado;
- sugestão de correção, quando disponível.

## Dados e credenciais

- Nunca versione `.env` ou bancos gerados em `data/`.
- Use somente uma chave da OpenAI com privilégios e limites adequados.
- O projeto não exige chaves de API do Datadog.
- Não indexe páginas privadas ou dados corporativos sem autorização e controles adicionais.
